# 🚗 Mechanic Dashboard - Task 3

## 📌 Overview

This project is a customized version of the Mazer Bootstrap 5 admin dashboard.
It has been redesigned into a **Mechanic Service Management Dashboard** with improved UI and structured components.

---

## 🎯 Features

* Dashboard with key metrics:

  * Total Customers
  * Vehicles Serviced
  * Revenue
  * Pending Requests

* Clients & Services Table

* Customer Feedback Section

* Responsive design using Bootstrap 5

* Clean and modern UI with custom color palette

---

## 🎨 UI Customization

* Applied a soft pastel color palette
* Modified layout and components to match a real-world mechanic dashboard
* Improved spacing, readability, and structure
* Replaced default branding with custom identity (Swaroop)

---

## 📊 Data Handling

Currently, data is displayed using static values for demonstration purposes.
A JSON-based dynamic data integration approach was also explored using JavaScript and Vite environment.

---

## 🛠️ Tech Stack

* HTML, CSS, Bootstrap 5
* JavaScript (ES6)
* Mazer Admin Template
* Vite

---

## 🚀 How to Run

```bash
npm install
npm run dev
```

Then open:

```
http://localhost:5173
```

---

## 📁 Project Structure

* `src/layouts` → Layout and sidebar
* `src/assets` → Styles and scripts
* `index.html` → Main dashboard page

---

## 📌 Note

This project focuses on frontend customization and UI/UX improvements based on an existing template, simulating real-world development scenarios.
